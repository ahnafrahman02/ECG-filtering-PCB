# ECG-filtering-PCB
4-layer mixed-signal PCB (51×19.3mm) for wearable smart glasses ECG monitoring, designed in KiCad. Integrates an ESP32-S3-MINI-1 (overhanging 2.4GHz antenna) and TI ADS1292 ECG front-end with dedicated internal planes, ferrite-bead isolation, 0-error ERC/DRC, and fabrication-ready Gerbers.
